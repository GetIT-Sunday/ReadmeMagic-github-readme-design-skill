# Score stage

Score source and candidate independently: core documentation (70 points), showcase enhancement (30 points), and reading experience (100 points). If no source README exists, report the baseline as unavailable rather than zero.

Report every finding with code, section, severity, evidence, remediation class, and scope.

Completion gate: core documentation is at least 56/70, reading experience is at least 80, and no blocking finding remains. Showcase points are an enhancement track; strict evidence is reported separately.
